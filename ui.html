5

Import into the new tenant

Recreates everything as real Teams messages with the original sender and date. Resumes where it stopped and never duplicates.

⚠️Before importing everything: every person must exist in the new tenant with a Teams license, and should have opened OneDrive once. Teams accepts about 5 messages per second per conversation, so large tenants take hours. The tool works on many conversations at once.

Finishing touches

Optional steps that close the gaps found in real migrations. Each needs a few extra permissions. See docs/permissions.md.

Recover missing media

Re-downloads images, voice notes and videos an earlier export missed (for example after a network drop).

Copy linked files

Messages often link to files in other people's OneDrive. This copies them into the new tenant so the links keep working.

Needs: old SharePoint name

Rebuild group chats

Rebuilds group chats so every old-tenant link points at its new copy, and adds meeting recordings at their original time.

Run “Copy linked files” first

Copy profile photos

Gives each matched user the same profile photo they had in the old tenant.

✓

Old-link clean-up

For a clean break between companies: removes messages that still show an old-tenant address, mostly in one-to-one chats, which Teams can't rebuild.

a. Find

Lists every imported message that still shows an old address, with its sender.

b. Post clean copies

Posts a copy right under each one: same sender, same time, no old address.

c. Delete originals

Opens a sign-in link in the log. The sender signs in and their originals are deleted. Repeat for each sender.

ℹ️Microsoft only lets the sender delete a message without a paid compliance license. Step c needs the delegated permissions and redirect address in docs/cleanup.md, and the sender needs a Teams license.
